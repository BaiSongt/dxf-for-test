# DXF for Test — 参数化 CAD 测试数据集

本仓库用于建立 **1000 套分 10 级的机械零件工程图基准数据集**。每套样本以参数化三维实体为几何真值源，同步生成 STEP 与 DXF，并关联尺寸、公差、PMI 与视图布局信息。

## 已实现：四个端到端基准样例

| 图号 | 难度 | 零件 | 三维模型 | 工程图视图 |
|---|---|---|---|---|
| L01-001 | L1 | 60×40×3 矩形薄板 | STEP | 单俯视图、尺寸、厚度说明 |
| L04-001 | L4 | 40/30/20 三级轴径、总长 120 的阶梯轴 | STEP | 主视图、端视图、轴向尺寸、直径公差、基准 A |
| L05-001 | L5 | 双键槽阶梯轴，轴径 ⌀40/⌀30/⌀24、总长 210 | STEP | 主视图 + A-A、B-B 两个真实断面，槽宽 12/8、槽深 4.5/3，12 个原生尺寸 |
| L06-001 | L6 | 160×110×40、主腔深 25、岛体及孔系的安装板 | STEP | 俯视图、A-A 剖视、B 局部详图（2:1）、尺寸及图形化 GD&T |

工程图的视图是按模型表达需要配置的，不强制每张图纸具备三视图。

## 运行

Python 建议 3.11 或 3.12。优先使用 Conda/Miniforge 环境安装 CAD 依赖（CadQuery 含 OCCT）：

```bash
python -m pip install -e '.[test]'
python -m dxf_for_test.generator --output samples
pytest -q
```

不需要 PNG 时可以使用 `--no-preview`。输出按零件编号分别保存：

```text
samples/
  L01-001/
    part.step
    drawing.dxf
    definition.json
    validation.json
    preview_3d.png
    preview_drawing.png
  L04-001/
  L05-001/
  L06-001/
  manifest.json
```

## 核心约束

- **唯一几何来源**：3D 精确实体先生成，正视、俯视、端视、剖视、局部详图均由同一 B-Rep 派生；不分别随机拼接图纸轮廓。
- **原生 DXF 尺寸**：可解析 `DIMENSION`，工程标注、基准、GD&T 使用独立图层；第一阶段 GD&T 采用可编辑图形框格，语义存在 JSON。
- **PMI 能力边界**：STEP 当前仅导出精确实体几何，不声称 STEP 内有 AP242 语义 PMI。后续另行实现 AP242 语义 PMI 与基准绑定。
- **键槽真实断面**：L05 的 A-A/B-B 分别在 X=28 和 X=174 处直接与 STEP 同源 B-Rep 截面求交，输出 ARC/LINE 与剖面填充；槽宽 ±0.04 和轴颈直径公差保存在原生 DIMENSION 参数中。
- **STEP 往返检验**：生成的 STEP 必须重新导入，实体合法且体积保持一致，否则生成失败。
- **真实剖切**：A-A 剖视由 B-Rep 的 Y=0 剖切实体投影，剖面填充对应实际剖切面；B 详图使用投影曲线裁剪与 2:1 比例。
- **可复现**：几何参数、体积、视图配置、标注 JSON 和 SHA256 均有记录。
- **基准不是生产工程图**：当前示例公差用于数据测试，正式生产零件需依据用途进行设计验证。

## 后续开发

1. 视图规划器由人工定义视图升级为自动选择主视/剖视/局部详图。
2. 将尺寸、GD&T 和基准与稳定的几何特征 ID 绑定，支持拓扑变化追踪。
3. 多零件族、多级随机种子与拓扑去重，扩展至每级 100 套。
4. 跨 CAD 应用的 DXF 兼容性抽检，尤其是汉字、尺寸引线和剖面线呈现。
5. STEP AP242 语义 PMI 单独认证，不与二维图形化标注混用。
