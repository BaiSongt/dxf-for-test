# 轴类工程图标注与视图规划规范（V1）

适用范围：纯回转体阶梯轴、带槽轴、带孔轴及后续参数化轴类样本。
参考 ISO 129-1:2018（尺寸表示）与 ISO 128 系列（视图、剖视、断面）；仍须跨 CAD 软件复核。

## 标注规则

1. 以轴线水平的纵向投影为主视图，中心线采用细点画线。
2. 直径与真实圆柱特征关联：尺寸测量点取该轴段两条实际投影母线，使用原生 DXF `DIMENSION`。
3. 直径文字使用 `⌀` 前缀，公差记录在尺寸样式中，不用脱离几何的 MTEXT 冒充尺寸。
4. 轴向尺寸安排在主视图下方，先局部分段长度、后总长；不得形成互相矛盾的封闭尺寸链。
5. 轴端直径尺寸优先布置在轮廓两侧，减少斜引线交叉；中间直径可竖向标注，文字移到轮廓上方。
6. 避免把尺寸文字压在零件轮廓内部；根据轴段长短决定标注线和文字位置。
7. 端视图、局部详图、断面图均按真实制造特征需求生成，不强制固定三视图。
8. 存在键槽、花键、交叉孔、退刀槽时，增加 A-A / B-B 断面或局部详图；剖面线由同一三维实体剖切结果生成。
9. 形位公差、基准和表面粗糙度必须绑定具体的几何要素，不因等级提高而虚构要求。
10. 普通毫米视图尺寸倍率为 1，局部放大的补偿不得改变最终真实尺寸；保留 DXF 实体句柄与 JSON 映射。

## 当前 L04-001

- 模型：三段同轴阶梯轴，长 40 / 50 / 30，总长 120，轴径 ⌀40 / ⌀30 / ⌀20。
- 视图：主视图和端视图；因为无键槽，不绘制虚假的断面图。
- 直径：⌀40、⌀30 ±0.05、⌀20 均为原生 DIMENSION，尺寸线关联各轴段真实轮廓。
- 长度：40、50、120 依次为近侧分段和外侧总长，末段 30 由尺寸链导出。
- 基准 A：指向 ⌀40 圆柱面，JSON 定义其导出轴线；粗糙度等暂不虚构。
- 回归：检查原生尺寸、DIMLFAC、长度尺寸分层、直径线布置、中心线和不产生无效剖面。
