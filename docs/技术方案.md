# 第一阶段 CAD 同源生成技术方案

## 目的

验证单一参数化 B-Rep 同时导出 STEP 与 DXF 工程图的可行性：简单零件不强制三视图，复杂零件真实生成剖视和局部详图，并且尺寸、PMI 有 JSON 标准答案。

## 职责分离

- `models.py`：零件族参数、拓扑构造和工程要求。
- `projection.py`：OCC 精确隐藏线投影、真实剖切和投影曲线 DXF 转换。
- `drawing.py`：视图布置、DXF 原生尺寸、基准与图形化公差、图框。
- `generator.py`：STEP/DXF/PNG 产出、JSON 数据索引与自动校验。
- `tests/`：几何一致性与输出文件回归测试。

## 第一阶段已实现边界

- L1：单俯视图；L4：主视+端视；L6：俯视+A-A 剖视+B 局部详图。
- 3D STEP 保存 B-Rep 精确实体，不用 STL 作为几何真值。
- 2D DXF R2018，mm 单位，原生尺寸实体；形位公差以图形化框格+JSON 语义表达。
- 剖视生成先切三维实体后以 HLR 投影；局部详图同源投影后按模型区域筛选并缩放。

## 尚未实现

- 全自动视图选择、尺寸冲突自动排版、所有工程图标准符号的原生表达与跨软件完整认证。
- STEP AP242 语义 PMI 写入和同源双向实体级语义追踪。
- 异形曲线完整解析 DXF 表达（复杂曲线第一阶段用离散折线近似；精确几何保留在 STEP）。
- 拓扑稳定标识与深层特征树。

这些限制不能在验收中隐去，必须作为后续阶段任务保留。

## 验收

- 3 个 STEP 形状均有效、单实体、体积与参数解析结果匹配。
- 3 个 DXF 重新读取并执行 `ezdxf.audit()` 无错误。
- 每个 DXF 有至少两个原生 `DIMENSION` 实体；视图数量符合方案。
- L6 具备剖面 HATCH 和来自原模型的局部详图曲线。
- 所有输出具备 JSON 参数、视图列表和文件 SHA256。
